# 💐 A Bouquet for You

A tiny, interactive web gift. Answer six quick questions and get an illustrated bouquet, the meaning of your flowers, and a short get-well note — all in a single HTML file.

## How it works

1. **Flower** — rose, daisy, tulip, sunflower, lavender or orchid
2. **Color** — options change depending on the flower
3. **Quantity** — 1, 3 or 7 stems
4. **Accent** — baby's breath, eucalyptus, fern, or none
5. **Wrapping** — kraft, white tissue, powder pink or dark green
6. **What you need right now** — sleep, a laugh, something to watch, or to be left alone

At the end, the bouquet is drawn and animated, the "language of flowers" for your choices is explained, and a playful florist receipt appears. Your choices can be shared over WhatsApp with one tap.

## Features

- Bouquet artwork generated entirely in code (SVG), no image files
- Automatic light and dark mode
- Respects reduced-motion settings
- Remembers the last bouquet on the device
- Mobile-first, single-column layout
- No frameworks, no libraries, no build step

## Customize

All personal settings (recipient name, signature, WhatsApp number, distance, and the "prepared by" line) live in the `AYAR` object at the top of the script in `index.html`.

## Run it

Download `index.html` and open it in any browser. That's it.
